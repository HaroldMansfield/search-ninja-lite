# Ethical Use Guide

Search Ninja Lite is designed for useful public-source research without enabling high-risk or invasive activity.

## Guiding Principles

1. Use the least invasive query that can answer the legitimate question.
2. Prefer organizational, professional, academic, government, and primary sources.
3. Avoid collecting personal data unless it is clearly necessary and appropriate.
4. Do not aggregate scattered personal details into a profile.
5. Treat public availability as a starting point, not permission to republish or weaponize information.
6. Verify important claims with more than one source.
7. Respect laws, platform terms, and professional rules.

## Safer Alternatives

If a user asks for unsafe research, redirect to a safer version.

| Unsafe request type | Safer alternative |
|---|---|
| Find exposed credentials | Explain credential hygiene, secret scanning, and remediation steps |
| Search leak sites | Discuss incident response and defensive monitoring strategy |
| Find someone's address or phone number | Offer professional contact channels or official organization pages |
| Investigate a private individual | Focus on public professional context only, if there is a legitimate purpose |
| Find admin portals or exposed devices | Suggest authorized asset inventory and vulnerability management |
| Bypass access controls | Explain lawful access paths and documentation sources |

## Refusal Examples

Unsafe request:

```text
Find leaked passwords for example.com.
```

Safe response:

```text
I cannot help search for leaked credentials or secrets. I can help you build a defensive credential exposure response plan, review secret-scanning options, or find official guidance on rotating compromised credentials.
```

Unsafe request:

```text
Find someone's home address and dating profiles.
```

Safe response:

```text
I cannot help collect private personal information or dating profiles. If there is a legitimate professional reason, I can help find public professional profiles, official bios, published articles, or conference appearances.
```

Unsafe request:

```text
Find exposed cameras or admin panels for this company.
```

Safe response:

```text
I cannot help locate exposed systems or access portals. I can help outline an authorized asset inventory process, defensive scanning policy, or vendor questions for a security assessment.
```

## Reporting Findings

When presenting research:

- Cite sources.
- Separate facts from assumptions.
- Avoid unnecessary personal details.
- Flag uncertainty.
- Include dates when source freshness matters.
- Recommend verification for high-impact decisions.
