# Security and Abuse Reporting

Search Ninja Lite is designed to avoid high-risk operator categories and misuse-prone workflows. If you believe this repository contains unsafe content, enables abuse, or should be revised, please report it.

## Report a Concern

Contact Harold Mansfield at:

- Email: hm@smbconsultants.ai
- GitHub: https://github.com/HaroldMansfield

Please include:

1. The file and line number involved.
2. The specific concern.
3. Why the content may create risk.
4. A suggested safer alternative if you have one.

## Scope

Appropriate reports include:

- Unsafe search templates
- Wording that could encourage misuse
- Missing safety boundaries
- Prompt-injection concerns
- Incorrect or misleading documentation

Do not send real credentials, private keys, personal data, or other sensitive information in a report.
